# Backend с микросервисами для маркетплейса

## Стек:

1. Laravel
2. Go
3. Mysql
4. Nginx
5. Docker / Docker-compose

## Уже написаны микросервисы:

1. Профиль (Laravel)
2. Каталог (Laravel)
3. Обработчик фото (Go)

## Профиль

Микросервис для авторизации / регистрации пользователей.

1. Хранит пользователей в своей отдельной БД
2. Создает JWT токен и передает его фронту <br>
   В токене есть вся нужная информация для его проверки в других сервисах)

## Каталог

Микросервис для работы с товарами

1. Хранит в своей отдельной БД
    <ul type="disc">
        <li>Товары</li>
        <li>Категории</li>
        <li>Атрибуты (названия характеристик)</li>
        <li>Значения для атрибутов</li>
        <li>Привязку возможных атрибутов для категорий</li>
        <li>Привязку между товаром, атрибутом и значением</li>
    </ul>
2. Есть маршруты для выдачи данных неавторизованным пользователям
3. Есть маршруты, доступные только админам для добавления / изменения / удаления данных

## Обработчик фото

Микросервис для создания разных размеров полученного фото и сохранения в облако

1. Есть 3 варианта размера фото (К названию фото добавляется суффикс)
    <ul type="disc">
        <li>Оригинал (Без суффикса)</li>
        <li>Large (Большая версия фото, если оригинал больше, чем large) (суффикс _large)</li>
        <li>Small (Маленькая версия фото, если оргинал больше, чем small) (суффикс _small)</li>
    </ul>
2. Обработчик доступен только админам
3. Так же по мимо новых размеров фото, изменяется формат на более легких webp для хранения

Например, из фото image.jpg в облако сохранится 3 фотографии
1. image.webp
2. image_large.webp
3. image_small.webp
